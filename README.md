# MNIST-image-classifier-practice
------------------------------------

Code repository for my independent skill development on machine learning. I've been practicing developing a basic MNIST image-classifier based upon a Convolutional Neural Network (CNN) owing to its superior processing of 2D matrices. 

This project serves as a precursor for a spatial-transcriptomic image classifier to use within my independent projects. My next steps are to look into using a 'confusion matrix' to see what the model is stumbling on. While an accuracy of 98.03% is fantastic in data science, it could prove lethal in a clinical context, so the goal is to learn how to close that gap as much as possible.
